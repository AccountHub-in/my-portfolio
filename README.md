# my-portfolio
# Satish's Portfolio Website

This repository contains the source code for a fully responsive personal portfolio website built for a full-stack developer named Satish. The website serves as a digital resume to showcase professional skills, educational history, work experience, and projects.

## 🚀 Features

*   **Responsive Design:** The layout automatically adapts to different screen sizes (mobile, tablet, and desktop) using CSS Flexbox and Grid layouts.
*   **Interactive UI:** Features smooth scrolling, floating animations, and scroll-triggered transitions like fade-ins and slide-ups.
*   **Navigation:** Includes a sticky header with a traditional navigation menu for desktops and a functional burger menu for mobile devices.
*   **Comprehensive Sections:** Organized into Home, About, Skills, Education, Experience, Projects, and Contact sections.
*   **Contact Form:** Includes a built-in form for visitors to send messages and request quotes.

## 🛠️ Tech Stack

*   **HTML5:** Provides the semantic structure of the website.
*   **CSS3:** Handles all styling, custom variables (colors, fonts), box shadows, and responsive media queries.
*   **JavaScript:** Manages text animations and mobile menu toggling (via `portfolio.js`).
*   **External Libraries:** Utilizes Google Fonts (Poppins and Roboto Slab) for typography and Font Awesome (v6.5.2) for UI icons.

## 📁 Assets & Imagery

The project incorporates several specific image assets to visually represent the developer's brand, tech stack, and background:
*   **Hero Character:** The main landing section utilizes a 3D character placeholder named charector.jpg.
*   **Skills Logos:** The professional skills section includes icons for various technologies, such as html,css.jpg, `js.jpg`, `php.jpg`, `mysql.jpg`, and `nodejs.jpg`.
*   **Education History:** The education timeline features images of past institutions, including ind.jpg for Indian Public School and `kk.jpg` for K.K College of Engineering and Management.

## 🏁 Getting Started

To view and interact with this project locally:

1.  Clone this repository to your local machine.
2.  Ensure all source files are kept in the same root directory, including `index.html`, `portfolio.css`, `portfolio.js`, and all image files like charector.jpg, html,css.jpg, and ind.jpg.
3.  Open the `index.html` file in your preferred modern web browser. No build tools or servers are strictly required to view the static site.
